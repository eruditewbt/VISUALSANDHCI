# VISUALSANDHCI

_Powered by EruditeWBT_

A public pathway for graphics, design, UI, UX, GUI, accessibility, and human-computer interaction inside the EruditeWBT ecosystem.

This repo exists so visual thinkers, designers, frontend beginners, and product-minded collaborators have a serious place to learn, practice, and contribute.

## What This Repo Covers

- graphics and visual communication
- interface design
- UI and GUI structure
- UX and task flow thinking
- HCI and accessibility
- design systems
- simple UI coding with HTML, CSS, JavaScript, and Flutter-ready thinking
- collaboration between designers, engineers, founders, and domain experts

## Start Here

1. Open the site in `docs/index.html`
2. Read the beginner path in `docs/start.html`
3. Practice visible interfaces first
4. Join the community and post your intent
5. Move into a live product or hackathon lane
